# ODOO-x-LDCE-2026-GlobeTrotter
## 📌 Overview

**GlobeTrotter** is a modern, full-stack travel companion and itinerary planner developed for the ODOO x LDCE Hackathon 2026. It simplifies journey planning by allowing travelers to discover destinations, generate custom daily itineraries, and manage travel preferences in real-time. 

Built with a high-performance **FastAPI (Python)** backend, a sleek **React (TypeScript + Vite)** frontend, and powered by **MongoDB Atlas** for reliable cloud persistence, GlobeTrotter delivers a seamless, responsive, and secure experience across devices.

---

### ✨ Key Features

* **Intelligent Trip Planning:** Build and customize multi-day itineraries tailored to your budget, style, and timeline.
* **Interactive Exploration:** Discover popular landmarks, activities, and local hotspots.
* **Real-Time Data Persistence:** Synchronize user preferences, saved routes, and active trips instantly with MongoDB Atlas.
* **Unified Single-Project Architecture:** Zero CORS friction with integrated API routing designed for seamless serverless deployment.
